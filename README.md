# weather-widget

A small static browser weather widget. The current active page uses the existing `weatherwidget.io` embed.

Canonical project details live under `project/docs/` rather than in this README:

## Current boundary

The checked-in manifest and service-worker files are retained Project-owned artifacts, but the current HTML does not activate them. This repository therefore does **not** currently claim installable or offline PWA behavior.

Runtime/PWA changes, weather-provider changes, and deployment behavior are outside this README entrypoint.
